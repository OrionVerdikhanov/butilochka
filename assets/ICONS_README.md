# Инструкции по созданию иконок

Для полноценной работы приложения необходимо добавить следующие изображения в папку `assets/`:

## Требуемые файлы:

### 1. icon.png
- Размер: 1024x1024 пикселей
- Формат: PNG
- Описание: Основная иконка приложения
- Рекомендация: Изображение бутылки на красном фоне (#ff6b6b)

### 2. splash.png
- Размер: 1284x2778 пикселей (для iPhone 14 Pro Max)
- Формат: PNG
- Описание: Экран загрузки приложения
- Рекомендация: Логотип игры с названием "Бутылочка" на красном фоне (#ff6b6b)

### 3. adaptive-icon.png
- Размер: 1024x1024 пикселей
- Формат: PNG с прозрачностью
- Описание: Адаптивная иконка для Android
- Рекомендация: То же изображение что и icon.png, но на прозрачном фоне

### 4. favicon.png
- Размер: 48x48 пикселей
- Формат: PNG
- Описание: Фавикон для веб-версии
- Рекомендация: Упрощенная версия основной иконки

## Как создать иконки:

### Вариант 1: Использовать онлайн-генераторы
1. Используйте сервис https://appicon.co/ или https://www.appicon.build/
2. Загрузите одно изображение 1024x1024
3. Сервис автоматически создаст все нужные размеры

### Вариант 2: Создать самостоятельно в графическом редакторе
1. Используйте Figma, Photoshop, или GIMP
2. Создайте квадратное изображение 1024x1024
3. Нарисуйте бутылку и добавьте цветовой акцент
4. Экспортируйте в нужных размерах

### Вариант 3: Использовать простые заглушки (для тестирования)
Создайте простые цветные квадраты с текстом:
- Красный фон (#ff6b6b)
- Белый текст "Бутылочка" или "🍾"

## Временное решение

Если вы хотите быстро запустить приложение для тестирования, вы можете:

1. Скачать любое изображение бутылки из интернета
2. Изменить размер до 1024x1024 с помощью онлайн-сервиса (например, https://www.iloveimg.com/resize-image)
3. Переименовать и скопировать файл для всех необходимых иконок

## Примечание

До добавления иконок приложение всё равно будет работать, но:
- Expo покажет стандартную иконку
- Экран загрузки будет пустым
- На устройстве будет дефолтная иконка

После добавления иконок перезапустите Expo сервер:
```bash
npm start -- --clear
```
