# Бутылочка - Мобильная игра для вечеринок

Веселая мобильная игра "Бутылочка" (Spin the Bottle) для Android с двумя увлекательными режимами!

## Описание

Классическая игра для компаний с современным интерфейсом и анимацией. Игра полностью локальная, не требует интернета, базы данных или сервера.

## Возможности

### Два режима игры:

1. **Режим "Желания"** - Крутящий игрок загадывает случайное желание из списка для того, на кого указало горлышко бутылочки

2. **Режим "Знакомства"** - Мужчины и женщины могут:
   - Поцеловаться
   - Поставить друг другу лайк
   - Пропустить ход

### Основной функционал:

- Добавление неограниченного количества игроков
- Указание имени и пола для каждого игрока
- Красивая анимация вращения бутылочки с физикой замедления
- Визуальное расположение игроков по кругу
- Счетчик лайков в режиме знакомств
- 30 готовых забавных желаний

## Технологии

- **React Native** с Expo для кроссплатформенной разработки
- **TypeScript** для типобезопасности
- **Animated API** для плавных анимаций
- Локальное хранилище состояния (без БД)

## Требования

- Node.js 16.x или выше
- npm или yarn
- Expo CLI
- Для Android: Android Studio или Expo Go app

## Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

или

```bash
yarn install
```

### 2. Запуск приложения

#### Вариант A: Использование Expo Go (быстрый способ)

1. Установите приложение "Expo Go" на ваш Android телефон из Google Play
2. Запустите проект:

```bash
npm start
```

3. Отсканируйте QR-код в терминале с помощью приложения Expo Go

#### Вариант B: Эмулятор Android

1. Установите Android Studio и настройте эмулятор
2. Запустите эмулятор
3. Запустите проект:

```bash
npm run android
```

#### Вариант C: Сборка APK для установки на устройство

```bash
# Установите EAS CLI
npm install -g eas-cli

# Инициализируйте EAS
eas build:configure

# Создайте билд для Android
eas build --platform android --profile preview
```

## Как играть

### Шаг 1: Добавление игроков

1. Введите имя игрока
2. Выберите пол (М/Ж)
3. Нажмите "Добавить"
4. Повторите для всех игроков (минимум 2)
5. Нажмите "Продолжить"

### Шаг 2: Выбор режима

Выберите один из двух режимов:

- **Желания** - доступен для любого состава игроков
- **Знакомства** - требует минимум 1 мужчину и 1 женщину

### Шаг 3: Игра

1. Нажмите кнопку "КРУТИТЬ"
2. Бутылочка начнет вращаться
3. После остановки появится результат:
   - **Режим "Желания"**: показывается случайное желание
   - **Режим "Знакомства"**: выбор действия (поцелуй/лайк/пропустить)

### Список желаний включает:

- Спеть песню
- Станцевать танец
- Рассказать анекдот
- Сделать 10 приседаний
- Изобразить животное
- И многое другое! (всего 30 желаний)

## Особенности реализации

### Анимация вращения

Бутылочка вращается с реалистичной физикой:
- Минимум 3 полных оборота
- Случайный угол остановки
- Плавное замедление (cubic easing)
- Длительность анимации: 3 секунды

### Расположение игроков

Игроки автоматически располагаются по кругу вокруг бутылочки:
- Динамическое вычисление позиций
- Цветовое кодирование по полу (синий/розовый)
- Подсветка текущего игрока и цели

### Логика режима "Знакомства"

- Автоматическое чередование мужчин и женщин
- Бутылочка всегда указывает на противоположный пол
- Счетчик взаимных лайков
- Визуальные индикаторы лайков
